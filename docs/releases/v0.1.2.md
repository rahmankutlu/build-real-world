# Build Real World v0.1.2

This patch release fixes Mermaid diagram rendering in production.

## Highlights

- Fixes the Ecommerce and Payment Platform workflow sequence diagrams, which failed to parse because a `;` inside a sequence message is a Mermaid statement separator.
- Hardens diagram rendering: serialized and cancellable renders, correct off-screen measurement, removal of leaked Mermaid error nodes, a neutral failure fallback, and retry after a transient chunk-load failure.
- Validates all 30 project diagrams with the pinned Mermaid 11.17.2 in `npm run validate`, with unit and Playwright regression coverage for both themes, enlargement, mobile layout, and the GitHub Pages base path.

There are no binary assets in this release; the site is deployed from the validated static export.
