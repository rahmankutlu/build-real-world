# Build Real World v0.1.3

This release sharpens the ten case studies and the public site around them: more readable diagrams, domain-specific scaling guidance, per-project social previews, and a deployment that only publishes what CI has tested.

## Highlights

- Rewrites the scale-evolution tables so every case study states its own starting architecture and the measured pressure that justifies each transition.
- Makes architecture diagrams legible: top-to-bottom layouts, a minimum rendered label size, and scrolling instead of shrinking wide diagrams.
- Loads Mermaid only when a diagram comes into view, and keeps table-of-contents jumps on target while diagrams render.
- Adds generated 1200×630 Open Graph images for the site and each project, PNG app icons, and visible breadcrumbs with matching structured data.
- Validates the exported site for unique titles and canonicals, descriptions, structured data, and resolvable image, sitemap, and feed URLs.
- Browser-tests both the root and GitHub Pages paths in CI, and deploys Pages from the exact artifact CI built after it passes on `main`.

There are no binary assets in this release; the site is deployed from the validated static export.
