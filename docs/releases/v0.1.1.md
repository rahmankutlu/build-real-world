# Build Real World v0.1.1

This release hardens the first public version of Build Real World: ten system-design case studies, seventeen engineering patterns, thirty edge cases, four learning paths, client-side search, and architecture comparison.

## Highlights

- Publishes the static application to its repository-scoped GitHub Pages URL with centralized base-path and canonical-URL handling.
- Adds complete page metadata, project-specific SEO, structured data, sitemap/robots/feed corrections, and a 1200×630 social preview.
- Improves the homepage, project explorer, mobile navigation, active project contents, diagram theming/enlargement, and URL-persistent search.
- Adds curated links between projects, patterns, failure cases, learning paths, and related systems.
- Replaces generic observability copy with domain-specific logs, metrics, traces, and alerting guidance across all ten projects.
- Introduces SEO and exported-site validation plus broader Playwright coverage for local and GitHub Pages paths.
- Clarifies the contributor template and the MIT code / CC BY 4.0 educational-content license split.
- Separates CI quality, build, and E2E jobs and limits Dependabot grouping to compatible minor and patch updates.

There are no binary assets in this release; the site is deployed from the validated static export.
